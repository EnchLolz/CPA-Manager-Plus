# 临时共享访问

Full Mode 可以为朋友创建独立的临时密钥，设置有效期、精确的模型白名单，以及总 Token 限额、估算美元费用限额或两者。进入 **配置面板 → 可视化编辑器 → 认证配置 → 共享访问**，点击 **创建共享密钥**。密钥明文只显示一次。

朋友需要使用 Manager Server 的公开地址，例如 `https://manager.example.com/share/v1`。反向代理必须将 `/share/v1/*` 路由到 Manager Server。普通 `/v1/*` 仍然路由到 CPA。共享密钥不会添加到 CPA 的普通 API 密钥列表，也不能直接用于 CPA。

支持 `GET /models`、`POST /chat/completions`、`POST /responses`、`POST /messages` 及 SSE 流式响应，可使用 Bearer 或 `x-api-key` 认证。不支持 WebSocket、后台任务、保存的响应或 `previous_response_id`。

每个请求完成后结算用量，因此**最后一个请求可能超过剩余额度**。每个密钥同时只允许一个生成请求，超额或并发请求返回 HTTP 429。到期和撤销会阻止新请求，已运行的请求可能完成。限额不会自动重置。

Token 包括输入、输出及缓存输入，已包含在输出中的推理 Token 不重复计算。美元费用依据配置的模型价格，支持缓存、上下文和服务层级价格，但不含工具专属费用。这是 API 等价估算，不是实际订阅扣费或订阅比例。创建费用限额前，必须为所有允许的模型配置输入和输出价格。至少设置一种正数限额，有效期最长一年。

密钥以哈希形式存储，用量和撤销状态在 SQLite 中持久化，不受普通请求历史保留策略影响。若请求中断、上游结果不明或缺少用量，密钥会暂停；如果服务在请求中途崩溃，重启后也不会清除进行中标记。检查 CPA 用量后，撤销旧密钥并按需要的剩余额度创建新密钥。

此功能需要 Full Mode，不依赖普通用量采集器。CPA 托管的轻量面板不能执行这些限制。详见[英文说明](../en/gateway/shared-access.md)。
